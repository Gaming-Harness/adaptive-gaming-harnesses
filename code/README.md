# Anonymous Supplementary Code (ICLR)

This archive is an **anonymous**, source-only supplement for double-blind review.

## Scope

- Training-free gaming harness / probing / knowledge code under `code/curriculum/`
- Experiment configs and design notes
- Absolute cluster paths, author/organization identifiers, and internal API
  endpoints have been replaced with placeholders

## Not included

- Model checkpoints
- Videos / figures / run outputs
- Credentials or personal information

## Environment placeholders

Set paths and secrets via environment variables or by editing configs:

- `/path/to/openha_eval`, `/path/to/openha_tasks`, `/path/to/vla_checkpoint`
- `MINESTUDIO_TOKEN`, `LLM_API_APP_ID` / `LLM_API_REQUEST_URL` (OpenAI-compatible gateway)
- `GEMINI_API_KEY` / `GOOGLE_API_KEY` if using a public Gemini endpoint

## Extract

```bash
tar -xzf gaming_harness_code_anonymous_iclr.tar.gz
```
